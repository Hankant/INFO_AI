# 概念核查与理论来源

本文件遵守项目的七项概念检查。未通过检查的术语只作为待测操作或自定义参数，不作为成熟理论概念。

## 1. Algorithm aversion / 算法厌恶

| 检查项 | 结论 |
| --- | --- |
| 原始术语 | `algorithm aversion`；算法厌恶 |
| 文献来源 | Dietvorst, Simmons, & Massey (2015), *Algorithm Aversion: People Erroneously Avoid Algorithms after Seeing Them Err*, DOI: [10.1037/xge0000033](https://doi.org/10.1037/xge0000033) |
| 理论定义 | 人们观察算法表现、特别是算法犯错后，比对人类预测者更快失去信心，并可能放弃总体上更优的算法。它首先是行为模式，不是已经确定的单一心理机制。 |
| 不包括 | 不是所有条件下都偏好人类；不是任何低 AI 使用率；也不等同于认为 AI 能力较低。 |
| 分析层级 | 个体对预测来源的信心与选择。 |
| 模型位置 | 既有现象和竞争性解释，不作为本研究自变量。 |
| 经验对应 | 观察同样错误后对人类/算法的信心变化、后续选择和依赖权重。 |
| 理论价值 | 区分“根据相同绩效信息进行来源中性的更新”和“来源标签导致不对称更新”。 |

使用限制：本 IDEA 如果只发现 AI 错误后采用下降，就是 algorithm aversion 的直接复现，不能宣称新理论。

## 2. Resistance to medical AI / 医疗 AI 抵触与 uniqueness neglect

| 检查项 | 结论 |
| --- | --- |
| 原始术语 | `resistance to medical artificial intelligence`; `uniqueness neglect` |
| 文献来源 | Longoni, Bonezzi, & Morewedge (2019), *Resistance to Medical Artificial Intelligence*, DOI: [10.1093/jcr/ucz013](https://doi.org/10.1093/jcr/ucz013) |
| 理论定义 | 消费者认为自动化医疗服务较难照顾个体独特特征，因此更不愿使用由 AI 提供、特别是替代人类提供者的医疗服务。 |
| 不包括 | 不是一般性的 AI 错误容忍参数；不能自动推广到招聘、驾驶或监管机构。 |
| 分析层级 | 个体消费者对医疗服务提供者的选择。 |
| 模型位置 | 医疗领域的竞争机制。 |
| 经验对应 | 使用意愿、保留价格、提供者选择以及独特性忽视测量。 |
| 理论价值 | 区分“来源本身受到惩罚”和“AI 被认为不能个性化处理案例”。 |

使用限制：如果主实验采用医疗情境，必须测量或排除 uniqueness neglect；更干净的首项实验应使用个体独特性较弱的标准化运营任务。

## 3. Evaluability hypothesis / 可评价性假说

| 检查项 | 结论 |
| --- | --- |
| 原始术语 | `evaluability hypothesis`; `joint evaluation`; `separate evaluation` |
| 文献来源 | Hsee (1996), *The Evaluability Hypothesis: An Explanation for Preference Reversals between Joint and Separate Evaluations of Alternatives*, DOI: [10.1006/obhd.1996.0077](https://doi.org/10.1006/obhd.1996.0077) |
| 理论定义 | 某些属性在单独评价时缺少参照、难以评价；并列呈现比较对象会提高这些属性的可评价性，从而改变属性权重和选择。 |
| 不包括 | 不等同于“提醒参与者理性一点”，也不保证任何偏差都必然消失。 |
| 分析层级 | 个体对备选方案的评价与选择。 |
| 模型位置 | 人类基准信息处理的理论来源；`joint vs separate evaluation` 是处理。 |
| 经验对应 | 单独评价候选系统，或同时提供同任务人类绩效的可比基准。 |
| 理论价值 | 区分“稳定的来源厌恶”和“缺少可比较基准导致性能属性难以评价”。 |

## 4. Acceptable error rate / 最高可接受错误率

| 检查项 | 结论 |
| --- | --- |
| 原始术语 | `acceptable error rate`；本项目使用“最高可接受错误率” |
| 文献来源 | Lenskjold et al. (2023), *Should artificial intelligence have lower acceptable error rates than humans?*, DOI: [10.1259/bjro.20220053](https://doi.org/10.1259/bjro.20220053) |
| 理论定义 | 对某一明确用途和后果结构，决策者仍愿意批准或使用一个来源时所容许的最大错误概率。这里把它作为决策阈值，而非人格态度。 |
| 不包括 | 不等于实际错误率、准确率信念、一般信任、满意度或道德可接受性。 |
| 分析层级 | 个体决策参数；汇总后可比较群体分布。 |
| 模型位置 | 主要因变量。 |
| 经验对应 | 随机化错误率的多次采用选择所形成的切换点；直接百分比题仅作次要测量。 |
| 理论价值 | 区分“认为 AI 更不准”和“在相信其同样准确时仍要求它更准”。 |

## 5. Required accuracy premium / 所需准确率溢价

这是本项目的**自定义经验估计量**，不是声称来自既有理论的构念。

\[
RAP=e_H^{threshold}-e_{AI}^{threshold}.
\]

- `RAP>0`：AI 必须达到比人类更低的错误率才被采用。
- `RAP=0`：没有来源特异的性能门槛。
- `RAP<0`：对 AI 的错误容忍高于对人类。

其分析层级是个体或样本平均的选择阈值；其理论价值在于把能力信念和采用门槛分开。正式写作时必须称为“本文定义的估计量”。

## 6. Asymmetric tolerance parameter `α`

| 检查项 | 结论 |
| --- | --- |
| 原始术语 | 原 PPT 自定义的 `asymmetric tolerance parameter`，未发现其作为同义成熟构念的直接来源 |
| 文献来源 | 原始 PPT 的行为扩展，不得反向归入 algorithm aversion 文献 |
| 理论定义 | 在性能信念、成本和后果相同的模型内，AI 单次错误相对人类单次错误获得的额外主观损失权重 |
| 不包括 | 不包括认为 AI 更可能犯错、错误更相关、更难补救或责任主体不同造成的差异 |
| 分析层级 | 个人选择模型参数；若由监管标准反推，则层级变为制度决策，不能混用 |
| 模型位置 | 待估结构参数，不是中介变量 |
| 经验对应 | 需要错误率、成本、损失与来源的联合变化，不能从单个 Likert 题或一项采用选择识别 |
| 理论价值 | 在排除能力信念和系统风险判断后，区分来源中性损失计算与来源特异损失权重 |

使用限制：V1 主分析先报告阈值和 `RAP`；只有选择单调、模型拟合良好且关键替代解释被处理后，才估计 `α`。

## 7. Stakeholder heterogeneity / 利益相关者异质性

这不是一个需要包装成新理论的心理构念，而是样本分层和外部效度问题。

- 主体：公众、组织管理者、领域专业人员、公共部门执行者。
- 分析层级：群体间参数差异。
- 测量：使用同一随机化任务、同一信息和同一阈值估计后比较。
- 竞争解释：知识、制度责任、个人风险暴露、职业激励和样本构成。
- 使用限制：不得把短 vignette 中的“请想象你是监管者”解释为真实监管者参数。

## 8. Error visibility 与 human benchmark information

当前不把二者写成成熟构念：

- `error visibility` 只作为信息格式操作，例如呈现单个事故、汇总频率或分布图；
- `human benchmark information` 指是否展示同一任务、同一审计口径下的人类绩效错误率；
- 两项处理必须分开随机化，否则无法判断效应来自 AI 错误更醒目，还是人类错误终于进入比较。

## 9. AI 非替代性判定

必须比较三类来源：

1. 人类专业团队；
2. 非学习型、规则驱动的统计系统；
3. 机器学习/AI 系统。

判定规则：

- `AI ≈ 规则系统 ≠ 人类`：一般算法/自动化来源效应，AI 不是理论必要条件。
- `AI ≠ 规则系统` 且性能证据与部署条件完全匹配：才有 AI 特异性证据。
- 三者在提供人类基准后收敛：主要机制是比较基准/可评价性。
- 三者始终相同：原 PPT 的来源特异参数不获支持。
