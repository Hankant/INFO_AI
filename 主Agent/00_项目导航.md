## 统一使用规则

1. 新 Agent 开始工作前先读 `主Agent/AGENTS.md` 和对应文章 README。
2. 每项任务只指定一个主写 Agent；审查 Agent 不直接覆盖主稿。
3. 新成果先写入对应文章目录或答辩目录，不再新建顶层 `outputs/某次任务名`。
4. `outputs/` 中的内容默认视为历史产出、证据或可回收组件；只有 README 明确指定的基准文件例外。
5. 所有当前基准由主 Agent 登记；专项 Agent 不自行宣布“最终版”。
