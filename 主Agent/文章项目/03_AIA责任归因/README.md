## 暂定方向

AIA / AI agent / AI-assisted action 中的责任归因问题。

可能问题包括：

- 当 AI 参与决策或行动后，人们如何在用户、AI、开发者、组织或平台之间分配责任？
- AI 的自主性、可解释性、错误类型、控制权分配是否影响 blame / responsibility / accountability？
- 人们是否会因为 AI 看起来更像 agent，而改变对责任、意图、能力和过错的判断？
