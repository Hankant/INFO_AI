## 三、Findings

### Finding 1（严重）：研究对象尚未定型，RQ 与理论机制没有闭合

**类型：概念问题 / 识别问题**

目前材料中至少有四个候选对象混在一起：

- 事后责任归因：责任、过错、accountability 分给谁；
- ownership dilution / responsibility sharing：行动后果是否不再归属于单一人类行动者；
- moral distance / delegated responsibility：AI 是否降低事前道德成本；
- dishonest behavior / unethical delegation：AI 是否让人更敢做不诚实行为。

这些不是同一个因变量。若不先选定主 RQ，实验会变成“AI 介入后测一堆责任相关问卷”，识别链条会断在理论层。导师会问：你到底研究的是事后归因心理，还是事前行为改变？如果是责任结构，为什么用 blame allocation 能识别？如果是道德距离，为什么事后 blame 是核心 DV？

**最需要补的内容：** 用一句话固定第三篇主问题。例如只能先在下面三类中选一个主轴：

- `AI participation -> responsibility attribution / accountability allocation`
- `AI delegation option -> moral distance -> unethical behavior`
- `AI agency / mind perception -> blame shifting / ownership dilution`

在主轴确定前，不应设计复杂实验。

### Finding 2（严重）：`action -> responsibility` 映射还没有转化为可识别实验比较

**类型：识别问题**

总框架要求第三篇识别 `action -> responsibility`，但当前材料还没有回答：什么 action？谁 action？AI 是建议者、执行者、默认决策者、解释者，还是代理人？responsibility 是被试自己的 felt responsibility，旁观者对 actor 的 blame，还是组织/平台/开发者之间的责任分配？

如果操控只是“有 AI / 无 AI”，无法判断差异来自：

- AI 标签效应；
- AI 自主性；
- 人类控制权减少；
- 可解释性输出；
- 决策结果好坏；
- 责任可以被策略性推给非人类对象。

**高风险追问：** 为什么你的 AI 条件能识别“责任结构改变”，而不是识别“看到 AI 标签后评价对象变多”？

**最需要补的内容：** 一个最小识别矩阵。至少要有能区分 `AI presence` 与 `control / delegation` 的比较，例如：

- 人自己决定；
- AI 建议，人最终决定；
- 人设定目标，AI 执行；
- AI 默认决定，人可 override。

但这只是候选结构，不能在未定 RQ 前直接定稿。

### Finding 3（严重）：如果把第三篇写成单纯 blame attribution，会与现有材料自己的红线冲突

**类型：概念问题 / 可删减点**

多个项目文件都提醒不要把第三篇收缩成单纯 blame。`总领引言_AI_as_Decision_Architecture_PPT大纲.md:189` 明确说第三篇更准确是 responsibility architecture，包括 decisional ownership、felt accountability、responsibility sharing 和 credit/blame allocation。`AI_as_Decision_Architecture_Intro_4-5slides_中文大纲.md:100` 也提醒不要提前把第三篇收缩成单纯 blame attribution。

如果后续实验只做“读一个 vignette，然后把 blame 分给 human / AI / developer / firm”，它会显得像伦理心理学常规 vignette，和前三篇总框架的 `decision architecture` 连接很弱。

**高风险追问：** 你的贡献和已有 blame attribution / moral agency / responsibility gap 文献相比在哪里？只是多了生成式 AI 场景吗？

**建议：** blame 可以作为一个 DV，但不应是唯一主 DV。更稳的因变量组合应围绕主 RQ 选择，而不是堆满所有责任词。

### Finding 4（中高）：实验如果同时操控 AI 自主性、可解释性、错误类型、控制权分配，会过重且识别变脏

**类型：操控冗余 / 实验负担问题**

第三篇 README 列出 AI 自主性、可解释性、错误类型、控制权分配等可能因素。这些都合理，但不能同时塞进主实验。否则设计会变成多因素 factorial：autonomy × explainability × error type × control × outcome valence × actor role。样本量、解释难度和答辩风险都会暴涨。

**高风险追问：** 你为什么非要同时操控这么多东西？哪一个是理论机制，哪一个只是边界条件？

**建议删减：** 主实验只保留一个核心操控和一个必要对照。其他因素放到后续 study 或探索性附录。优先删掉那些不能直接改变识别比较的“好看但无贡献”变量，比如泛泛的 AI 透明度描述、长篇解释材料、多个场景重复但无机制差异的 vignette。

### Finding 5（中高）：`moral distance / dishonest behavior` 是有潜力的升级方向，但不能和责任归因混写成一个无序包

**类型：概念问题 / 识别问题**

本地综述材料建议将第三篇从“责任归因”升级为“道德距离与责任外包”，并引用 delegated responsibility / dishonest behavior 方向。这是更强的方向，因为它把问题从事后评价推进到事前行为。但它同时意味着实验 DV 可能从问卷归因变成真实行为，例如是否作弊、是否选择让 AI 执行不舒服决定、是否设定模糊目标。

如果报告中既说研究 responsibility attribution，又把核心贡献写成 AI 增加不诚实行为，但实验只测事后 blame，那么理论与 DV 不匹配。

**最需要补的内容：** 明确主 DV 是行为还是归因。如果主张是“责任外包降低道德成本”，则至少需要一个行为型 DV 或激励相容选择，而不能只靠 blame rating。

### Finding 6（中等）：第三篇与第二篇的边界容易混

**类型：概念问题 / 可删减点**

第二篇已经处理 reliance、delegation、control、architecture choice trajectory。第三篇如果也用“选择 AI / 人类 / 默认 / override”作为主要行为，并把授权水平当 DV，就会和第二篇撞车。第三篇必须把 action 后的责任结构或道德成本作为核心，而不是继续研究 reliance calibration。

**区分方式：**

- 第二篇问：反馈如何改变后续依赖和授权阈值？
- 第三篇应问：采取或委托行动后，责任、道德成本和 ownership 如何被重新分配？

**建议删减：** 不要把第三篇写成另一个 multi-round role learning / EWA 实验。除非用户明确要求，否则第三篇应避免沿用第二篇的动态授权模型。

### Finding 7（中等）：文献边界仍待补，不能只靠总框架支撑实验

**类型：概念问题**

共享文献库 README 明确说 AIA 责任归因方向待补，关键词包括 responsibility attribution、AI agency、moral agency、blame、accountability、control、intentionality、responsibility gap。现有本地综述提供了一些种子，但还不是正式文献矩阵。

**高风险追问：** 你的实验操控为什么来自这些理论，而不是临时拼出来的 AI 特征？

**最需要补的内容：** 在实验设计前先补一个精简理论表：每个构念对应哪条文献、预测什么方向、需要哪个操控、对应哪个 DV。

## 四、按类别汇总

### 概念问题

1. 第三篇目前同时漂浮在责任归因、责任结构、道德距离、不诚实行为、AI agency / mind perception 几个概念之间。
2. `ownership dilution`、`responsibility sharing`、`moral distance`、`blame shifting` 需要被明确区分，而不是互当同义词。
3. 不能把第三篇降格成“AI blame vignette”；项目材料已经明确要求避免这一点。

### 识别问题

1. 缺少最小实验比较：无法区分 AI 标签、控制权让渡、AI 自主性、解释性输出和结果 valence。
2. 缺少明确主 DV：行为型不诚实、事后 blame、felt responsibility、accountability allocation 不能同时都当主结果。
3. 如果主张 responsibility architecture，需要说明责任结构如何在实验中被改变，而不是只测人们怎么分配责任。

### 操控冗余

1. AI 自主性、可解释性、错误类型、控制权分配都可能重要，但不能全部进入主实验。
2. 多场景、多角色、多责任对象同时出现，会导致解释空间过大。
3. 与识别无关的 AI 描述文本、透明度说明、复杂组织背景应删除或压缩。

### 实验负担问题

1. 目前没有成型实验，若后续按所有关键词展开，会天然过重。
2. 不建议直接设计大型多因素 vignette，也不建议复用第二篇的多轮授权模型。
3. 预实验最应验证的是：被试是否理解 action、delegation、control、accountability 的差异，而不是一次性测试全部理论变量。

### 可删减点

1. 删除“单纯 blame attribution 是第三篇核心”的写法。
2. 删除与第二篇重复的 reliance / role learning / EWA 主线。
3. 删除不服务识别的泛泛 AI 特征操控，如笼统的“AI 更自主 / 更可解释”但没有机制定义。
4. 删除过多责任对象，先从 human actor、AI system、organization / developer 中选择最少必要对象。

## 五、下一步最需要补什么

第三篇下一步不应直接写完整实验，而应先补一个一页式设计锁定表：

| 模块 | 必须回答的问题 |
| --- | --- |
| 主 RQ | 研究责任归因、责任外包，还是道德距离导致的行为改变？ |
| 核心机制 | ownership dilution、mind perception、control loss、moral wiggle room 中哪一个是主机制？ |
| 最小操控 | 哪一个实验差异能唯一改变核心机制？ |
| 主 DV | blame allocation、felt responsibility、accountability allocation、dishonest behavior 中哪一个是主结果？ |
| 识别比较 | 哪两个或三个条件的比较能排除 AI 标签、能力差异和结果差异？ |
| 与第二篇边界 | 为什么这不是 reliance calibration / delegation learning 的重复？ |

只有这张表稳定后，才适合进入正式实验矩阵。
