# Info_AI 项目入口

本工作区分为实验工程、博士论文、国自然子课题和共享材料。项目规则见 [主控说明](主Agent/AGENTS.md)。

| 分区 | 入口 | 管理方式 |
| --- | --- | --- |
| 实验工程 | [Paper 2 实验](projects/paper2-slot-prototype/README.md) | 独立本地 Git 仓库；同步时优先处理 |
| 博士论文 | [三篇文章](主Agent/文章项目/README.md) | 原研究仓库，分别维护各篇基准 |
| 国自然题目一 | [材料入口](国家自科基金题目一/README.md) | 原研究仓库，独立子项目 |
| 国自然题目四 | [材料入口](国家自科基金题目四/README.md) | 原研究仓库，独立子项目 |
| 共享文献 | [共享入口](主Agent/共享文献库/README.md) | 原研究仓库，遵守既有维护边界 |
| 答辩材料 | [答辩入口](主Agent/答辩材料/README.md) | 原研究仓库 |

实验目录保留原路径，但有自己的 `.git`，不是原仓库的子模块。原仓库忽略该目录。重新克隆研究仓库不会自动取得实验代码。

详细操作见 [仓库管理与同步规则](docs/REPOSITORY_MANAGEMENT.md)。历史交付仍保留原位置，以维持已有链接；`outputs/`、`tmp/` 和根目录旧演示材料不作为新的开发入口。
